# Back-end Start Up Instructions

### 1. Create a '.env' file in the root directory.

### 2. Install MongoDB server and start it.

### 3. Create a MongoDB database with a name of your choice and then add it to the 'MONGODB_URI' field of the .env file.

### 4. Run 'npm install'.

### 5. Start the back-end by typing 'node app.js'. You will then be able to navigate to the driver search page, driver creation page, and rider creation pages under http://localhost:8080.
